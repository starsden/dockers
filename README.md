# Автономная система запуска заданий для школьных соревнований CTF

Готовое решение для развертывания динамических изолированных заданий (Web, FTP, Linux OS) на соревнованиях CTF без подключения к интернету во время проведения.

---

## Ключевые возможности

- 🚀 **3 готовых шаблона**:
  - `templates/web`: Легковесный Nginx на Alpine с поддержкой произвольных портов.
  - `templates/ftp`: Сервер vsftpd на Alpine (анонимный доступ или по паролю, пассивный режим).
  - `templates/os`: Базовая Linux-система на Alpine с SSH, утилитами диагностики и скриптами автозапуска.
- 🔒 **Полная автономность (Offline)**: Образы собираются заранее; во время соревнований интернет не требуется, внешние запросы контейнеров блокируются изолированной сетью `ctf_internal`.
- 🧼 **Принцип «Чистого листа»**: Данные заданий монтируются в контейнеры строго в режиме Read-Only (`:ro`). Любые изменения стираются при остановке инстанса.
- ⏱️ **Управление временем жизни (TTL)**: Автоматическое удаление контейнеров по истечении заданного таймера (по умолчанию 15 минут) и кнопка ручной остановки.
- 🤼 **Мультиплеер без конфликтов**: Каждому участнику динамически выделяется собственный диапазон портов на IP-адресе хоста (например, `30010-30019`).
- 🔗 **Простая интеграция с CTFd**: В описание задания вставляется обычная ссылка или iframe на портал лончера. Не требуется установка сложных плагинов.
- 💡 **Без сторонних зависимостей**: Сервер управления написан на стандартной библиотеке Python 3 (не требует `pip install`).

---

## Быстрый старт

1. **Собрать образы шаблонов (выполняется при наличии интернета):**
   ```bash
   ./scripts/build_templates.sh
   ```

2. **Настроить IP-адрес сервера:**
   В файле `launcher/config.py` укажите IP-адрес сетевого интерфейса, доступного участникам:
   ```python
   HOST_IP = "192.168.1.100"
   ```

3. **Запустить сервис лончера:**
   ```bash
   ./scripts/start_launcher.sh
   ```
   Веб-интерфейс будет доступен по адресу `http://<HOST_IP>:8080`.
